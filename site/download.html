Requirements

  • Windows 10, 11, or Windows Server 2019 and later, 64-bit. Tested on Windows Server 2019.
  • A local administrator account to install the service.
  • About 4 MB of disk space.
  • Windows 10 and 11 desktops: not tested yet.
  • 32-bit: build from source with cargo win32 (not tested yet).

Before you install

  • Early previewUse a test PC. Don't deploy it in production yet.
  • Not code-signed yetSmartScreen will warn you. Check the hash below before you run it.

Check the download

Compare the SHA-256 hash with the one in SHA256SUMS.txt on the release page. If they differ, delete the file.

Windows PowerShell
PS C:\Setup> Get-FileHash .\RunAdminGate-x64.zip -Algorithm SHA256

Build from source

You need Rust 1.80 or newer. Releases are cross-compiled from macOS or Linux with mingw-w64. Building on Windows with cargo build --release should also work but hasn't been tested.

Terminal
$ git clone https://github.com/UnkAtreus/run-admin-gate.git
$ cd run-admin-gate
$ cargo test                               # allow-list tests, any OS
$ rustup target add x86_64-pc-windows-gnu  # once; needs mingw-w64
$ cargo win                                # 64-bit build
$ cargo win32                              # 32-bit build

The programs land in target/x86_64-pc-windows-gnu/release/ (or i686-pc-windows-gnu for 32-bit).

What's in 0.2.0

Included

  • Service and launcher that start allowed programs on the user's desktop as SYSTEM, or as the user with administrator rights (new in 0.2.0)
  • Allow-list by program, folder, subfolders or pattern, with argument rules
  • Manager window with rule checking
  • Desktop and Start menu shortcuts with the app's icon
  • Open with entries per app and file type
  • Event Log entries for every start, refusal and failure
  • Silent install and uninstall with exit codes

Planned

  • Warning for allowed folders that users can write to
  • ADMX template for Group Policy
  • Code-signed releases
  • Testing on Windows 10 and 11 desktops
